    4️⃣ CSV Import/Export

    📋 CSV / Raw Data Format Requirements:

    Column Sequence (5 columns, comma-separated):
    1️⃣ Date (DD-MM-YYYY, e.g. 15-06-2024) | 2️⃣ Description | 3️⃣ Main Category | 4️⃣ Sub Category | 5️⃣ Amount (positive = income, negative = expense)

    Example: 15-06-2024, Grocery shopping, Food, Groceries, 2500.00
    Example: 16-06-2024, Coffee, Food, Dining, -350.00
    Example: "17-06-2024","Salary","Income","Monthly Salary",50000.00
    Day always comes first: 03-04-2026 = 3 April 2026. Also accepted: 15/06/2024, 15.06.2024, 2024-06-15, 15 Jun 2024.

    Export your data to CSV file, import from CSV file, or paste raw CSV data directly.

    Note: CSV import will add new entries. Existing entries with same ID will be updated. Required columns: Date, Description, Main Category, Sub Category, Amount (in that exact order)
